## O que mudou

- **Atualização que instala de verdade.** Ao clicar para instalar, o instalador era fechado junto com o app e nada mudava. Agora ele continua aberto e conclui a instalação.
- **Download bem menor.** A interface antiga em Qt saiu do pacote; o app usa só a interface nova. Ao atualizar, os arquivos antigos são removidos da pasta de instalação.

### Também nesta versão (vindo da 1.7.0)

- **Projetos.** A tela inicial agora lista projetos: escolha a pasta do jogo em qualquer nível e o app encontra os XMLs e o executável. Cada jogo pode ter vários idiomas.
- **Seleção inteligente de campos.** IDs, números e caminhos ficam escondidos; o app sugere os campos de texto e carrega várias tags de uma vez. Perfil pronto para Marvel: Avengers Alliance Redux.
- **Traduzir o projeto inteiro.** Com confirmação, cancelamento imediato e retomada de onde parou. No Gemini, textos repetidos são traduzidos uma vez, os pedidos vão em paralelo e os nomes saem primeiro para manter a consistência.
- **Testar no jogo.** Aplique a tradução com backup automático, jogue direto pelo app e restaure os originais quando quiser.
- **Builds novas do jogo.** O projeto passa para a build nova reaproveitando o que já foi traduzido; textos alterados ficam para revisar.
- **Histórico e memória de tradução.** Busca em todo o projeto, sugestões de traduções anteriores e restauração de qualquer versão de uma entrada.
- **Importar e compartilhar.** Importe uma tradução feita à mão na pasta do jogo e troque traduções com pacotes .stzpack.
- **Ajuda.** Nova tela de perguntas frequentes com busca, em 5 idiomas.
- **Agentes de código.** Servidor MCP para Claude Code, Codex e Cursor colaborarem na tradução.

## What's new

- **Updates that actually install.** Clicking install closed the installer together with the app, so nothing changed. It now stays open and finishes the installation.
- **Much smaller download.** The old Qt interface is gone from the package; the app uses only the new interface. Updating removes the old files from the install folder.

### Also in this version (from 1.7.0)

- **Projects.** The start screen now lists projects: pick the game folder at any level and the app finds the XMLs and the executable. Each game can have several languages.
- **Smart field selection.** IDs, numbers and paths stay hidden; the app suggests the text fields and loads several tags at once. Ready-made profile for Marvel: Avengers Alliance Redux.
- **Translate the whole project.** With confirmation, instant cancel and resume where it stopped. With Gemini, repeated texts are translated once, requests run in parallel and names go first for consistency.
- **Test in the game.** Apply the translation with an automatic backup, play from the app and restore the originals at any time.
- **New game builds.** The project moves to the new build reusing what was already translated; changed texts are marked for review.
- **History and translation memory.** Project-wide search, suggestions from earlier translations and restore of any version of an entry.
- **Import and share.** Import a translation made by hand in the game folder and exchange translations with .stzpack packages.
- **Help.** New searchable FAQ screen, in 5 languages.
- **Coding agents.** MCP server so Claude Code, Codex and Cursor can collaborate on the translation.
